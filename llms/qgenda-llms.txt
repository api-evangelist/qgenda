# QGenda REST API

> QGenda is a healthcare workforce management platform for physician and staff scheduling, on-call management, credentialing, provider data, time tracking, and clinical operations. The QGenda REST API (v2) exposes 146 operations across scheduling, staff, tasks, requests, pay, locations, and workflows. Base URL: https://api.qgenda.com/v2. Token-based auth via POST /v2/login; HTTPS TLS 1.2/1.3 only; JSON payloads; OData query support on select resources.

## APIs
- [QGenda REST API v2](https://api.qgenda.com/v2): 146 operations — scheduling, staff members, tasks, requests, pay codes/rates, locations, workflows.
